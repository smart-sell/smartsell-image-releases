# 스마트셀 이미지

스마트셀 셀러를 위한 데스크톱 앱의 **설치 파일**만 올리는 곳입니다. 소스 코드는 여기에 없습니다.

- 내 ChatGPT로 상품 이미지를 여러 장 한꺼번에 만들어요.
- 중국어 상세페이지를 통째로 넣으면 원래 장수·크기 그대로 한국어로 옮겨요.
- 스마트셀 계정으로 로그인해야 쓸 수 있어요.

## 받기

[최신 버전](https://github.com/smart-sell/smartsell-image-releases/releases/latest)에서 내 컴퓨터에 맞는 파일을 받으세요.

| 파일 | 컴퓨터 |
|---|---|
| `SmartSellImage-mac-arm64.dmg` | Apple Silicon Mac (M1 이후) |
| `SmartSellImage-mac-x64.dmg` | Intel Mac |
| `SmartSellImage-Setup-win-x64.exe` | Windows 10 이상 64비트 |

## 처음 열 때

- **Mac**: «확인되지 않은 개발자» 안내가 뜨면 시스템 설정 → 개인정보 보호 및 보안에서 맨 아래 「그래도 열기」를 눌러요.
- **Windows**: «Windows의 PC 보호» 창이 뜨면 「추가 정보」 → 「실행」을 눌러요.

자세한 안내는 스마트셀 → **이미지 앱** 페이지에 있습니다.
