# 이미지 스튜디오

데스크톱 앱의 **설치 파일**만 올리는 곳입니다. 소스 코드는 여기에 없습니다.

## 받기

[최신 버전](https://github.com/smart-sell/smartsell-image-releases/releases/latest)에서 내 컴퓨터에 맞는 파일을 받으세요.

| 파일 | 컴퓨터 |
|---|---|
| `ImageStudio-mac-arm64.dmg` | Apple Silicon Mac (M1 이후) |
| `ImageStudio-mac-x64.dmg` | Intel Mac |
| `ImageStudio-Setup-win-x64.exe` | Windows 10 이상 64비트 |

## 처음 열 때

- **Mac**: «열지 않음» 창이 뜨면 시스템 설정 → 개인정보 보호 및 보안에서 맨 아래 「그래도 열기」를 눌러요.
- **Windows**: «Windows의 PC 보호» 창이 뜨면 「추가 정보」 → 「실행」을 눌러요.

이 앱은 사용권으로 제공되는 상용 소프트웨어입니다. 역분석과 로직·프롬프트의 추출은 허용되지 않습니다.
